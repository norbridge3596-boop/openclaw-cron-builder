# ⏰ OpenClaw Cron Builder

A visual cron expression builder designed for the [OpenClaw](https://openclaw.ai) community.

## Features

- **Quick Templates** — One-click presets for common schedules (every hour, every 6 hours, daily 9 AM, weekdays, etc.)
- **Manual Builder** — Dropdown-driven cron expression builder with minute, hour, day-of-month, month, and day-of-week selectors
- **Human-Readable Descriptions** — Instantly see "Every 6 hours at :15 past, weekdays" instead of `15 */6 * * 1-5`
- **Next 5 Trigger Times** — Preview the next 5 times your cron will fire
- **Raw Expression Input** — Type any cron expression directly
- **OpenClaw Config Snippet** — Generates ready-to-paste JSON config for OpenClaw cron jobs
- **Dark Theme** — GitHub-dark-mode inspired UI, easy on the eyes

## Live Demo

[https://norbridge3596-boop.github.io/openclaw-cron-builder/](https://norbridge3596-boop.github.io/openclaw-cron-builder/)

## Why?

OpenClaw supports cron-based scheduling for agent jobs, but there was no tool to visually build and preview expressions. This fills that gap for the community.
